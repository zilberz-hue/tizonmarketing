# טיזון שיווק

אתר שיווק סטטי בעברית (RTL). פתחו את `index.html` בדפדפן, או הריצו `python3 -m http.server`.

התאימו תוכן, צבעים (`:root` ב-`style.css`) וחיבור הטופס (`script.js`).

## מערכת שיווק ופרסום

פתחו `app/index.html`. כוללת: מתכנן קמפיינים, לוח תוכן ותזמון (עם תזכורות), צנרת לידים, ודוחות (עלות לליד, ROAS, המרה). הנתונים נשמרים בדפדפן; ייצוא/ייבוא JSON לשיתוף בצוות.

הערה: פרסום אוטומטי לרשתות דורש חיבור ל-API של כל פלטפורמה ושרת – כרגע המערכת מתזכרת ומאפשרת העתקה מהירה.
